Version 1.0.08.8 - First-Run Finder Skin Handoff and Persistence

- Finalized the Finder + Finder Skin first-run experience from installation through the ready-to-use Home screen.
- Finder now installs Finder Skin on demand when the integrated interface is selected, activates it, and continues directly into Finder Skin Pre-Config.
- Serialized Pre-Config, Primary Tracker selection, account authorization and initial tracker synchronization so setup windows do not race one another.
- After the selected tracker is ready, Finder persists skin.finder as Kodi's selected skin, performs the final Finder Skin load, allows the interface to settle, and opens a fresh Home screen.
- The completed Home screen is now the end of first-run setup: users can begin using Finder immediately and do not need to back out of an Add-ons window, manually select Finder Skin, or exit/restart Kodi.
- Finder Skin remains selected across subsequent Kodi restarts.
- Preserved PunchPlay watched-history/list synchronization, In Progress widget refresh, Repair PunchPlay Watched Database, and the existing first-run authorization/rebuild logic.
- Updated the Setup Guide and relevant Tips to describe the completed automatic first-run behavior.
