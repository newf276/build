Version 1.0.03

PunchPlay Integration

• Fixed PunchPlay Collection Add and Remove Endpoints to match the working PunchPlay API contract.
• Collection writes now use the /collection and /collection/{item_id} endpoints.
• Collection Add requests now include format=digital.
• Added PunchPlay Collection and PunchPlay Personal List targets to Quick Add and Context Selection.
• Added a one-time Primary Tracker Selection prompt during installation, allowing Finder, Trakt, or PunchPlay to be selected.
• Selecting PunchPlay as the Primary Tracker rebuilds watched history and verifies Watchlist, Collection, and Personal Lists.
• Added the PunchPlay Lists Manager with Watchlist, Collection, and Personal List actions to the Context Menu.
• Added startup authorization validation and load notifications.

Version 1.0.02

Core Improvements and Platform Support

• Cross-Platform Compatibility: Compatible with major Kodi platforms, including Google TV, Android TV, and LibreELEC.
• Kodi 22 Support: Optimized for Kodi 22 (Piers).
• Repository-Driven Updates: Removed the built-in updater. Finder updates are now delivered directly through the Finder repository using Kodi's native repository update system.


PunchPlay Integration

• Added PunchPlay as a Primary Tracker and Lists Provider.
• PunchPlay Watchlists, Collections, and Personal Lists are supported alongside TMDb and Trakt.
• Added a Database Repair Tool under the Maintenance Tools to help restore correct movie and TV show synchronization and rendering when an initial scrape fails.
• Added Quick Add functionality for adding or removing movies and TV shows from the PunchPlay Watchlist.
• Quick Add can be enabled under Finder Addon > Content Section and its position can be adjusted in the Context Menu settings.
• Added Tracked Progress support. The In Progress and Next Up shelves follow the currently selected Primary Tracker and are displayed at the bottom of the Main TV Show Menu.

Deferred or Excluded Features

• Simkl Integration: Excluded from current development.
• MDBList.com Integration: Development is currently on hold pending resolution of minor bugs and improvements to authentication methods.


Configuration and Developer Notes

• Custom API Keys: Personal API keys for Trakt, TMDb, and PunchPlay can be added by editing settings_schema.json in the resources/data/ directory. Testing keys are included for initial functionality. Replacing them with personal API keys is recommended for long-term stability.
• Scraper Support: Finder supports most popular scrapers. Magneto is recommended and is included as the pre-configured scraper.
• Credits: Special thanks to silencebob2 for his work on Forge. Finder retains the efficient JSON settings schema approach used to keep the add-on lightweight and responsive.
