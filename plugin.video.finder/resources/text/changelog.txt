Finder — Kodi 22 (Piers)

Current Version: 1.0.05
Phase 2 Finalization: October 2026


Version 1.0.05 — Phase 2 Finalization

Finder Skin Integration

• Added first-use interface selection between Finder + Finder Skin and Finder Standalone.
• Added Finder Interface Setup under Tools so the saved interface mode can be changed later.
• Finder only opens the Finder Skin Pre-Config selector when skin.finder is the active Kodi skin.
• Finalized integrated Finder Skin Search behavior, including Recent Searches and stable result-control handling for submitted searches.
• Finalized Finder Skin TV widgets using Finder-native Genres, Categories, In Progress, Popular Today, Recently Trending, Most Watched, Providers, and Networks.


Native MDbList Ratings

• Added Finder's native MDbList ratings-display service for Finder Skin.
• Removed the need for a separate FENtastic/Finder helper add-on for MDbList ratings.
• Supports available IMDb, IMDb Popular, Metacritic, Rotten Tomatoes critic and audience, and TMDb rating displays.
• Added local MDbList rating caching and immediate use of an updated MDbList API key.
• MDbList integration in Phase 2 is ratings display only; it is not a Primary Tracker or watched-state provider. Finder, Trakt, and PunchPlay remain the Primary Tracker choices.


Native Trailer Playback

• Added native Finder trailer playback for Movies and TV Shows.
• Play Trailer from the Finder context menu now routes directly through Finder.
• Extras Play Trailer and Extras video selections now use Finder's native trailer resolver.
• Removed Finder's dependency on plugin.video.youtube for trailer playback.
• Added compatibility for metadata cached by older Finder versions so legacy plugin.video.youtube trailer URLs are converted to Finder's native route without requiring a metadata-cache clear.
• Uses Kodi InputStream Adaptive when an adaptive trailer stream is supplied.


PunchPlay and Tracker Improvements

• Added PunchPlay as a Primary Tracker alongside Finder and Trakt.
• First-run PunchPlay setup synchronizes watched history and validates Watchlist, Collection, and Personal List data.
• Added PunchPlay Watchlist, Collection, and Personal List management.
• Added PunchPlay Lists Manager and Quick Add integration.
• Added Trakt and PunchPlay additive list-transfer tools while preserving existing content.
• Added alphabetical sorting options for PunchPlay Watchlist and Collection.
• Added Clear PunchPlay Cache in Finder settings to rebuild local PunchPlay watched-state data without revoking authorization.
• Retained Repair PunchPlay Watched Database for recovery and troubleshooting.


General Finder Improvements

• Updated Finder for Kodi 22 (Piers) behavior and compatibility.
• Removed the old built-in Finder updater; updates are delivered through Kodi's repository update system.
• Updated menu, provider, network, and PunchPlay artwork to a consistent monochrome Finder style.
• Reworked Tools -> Tips for Use so the guide reflects Finder's current tracker, skin-integration, cache, ratings, widget, Search, and trailer features.


Version 1.0.05

• Reworked the Kodi changelog display and documentation formatting.
• Unified TV Network and Movie/TV Provider menu artwork with Finder's monochrome icon style.
• Removed the full-colour TMDb provider-logo fallback from navigation menus.
• Rewrote Finder's Tips system to match the current feature set at that stage of development.


Version 1.0.03

PunchPlay Integration

• Corrected PunchPlay Collection add and remove endpoints.
• Added PunchPlay Collection and Personal List targets to Quick Add and context selection.
• Added Primary Tracker selection for Finder, Trakt, or PunchPlay.
• Added PunchPlay Watchlist, Collection, Personal Lists, startup validation, and list-management actions.
• Added additive Trakt/PunchPlay transfers for supported Watchlists, Collections, and Personal Lists.


Version 1.0.02

Core Improvements

• Added PunchPlay support alongside TMDb and Trakt.
• Added tracked progress support for In Progress and Next Episodes using the selected Primary Tracker.
