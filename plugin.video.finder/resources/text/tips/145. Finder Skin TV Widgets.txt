Finder Skin's finalized TV Show widget set is designed around Finder's native lists and navigation.

The default TV widget sequence is Genres, Categories, In Progress, Popular Today, Recently Trending, Most Watched, Providers and Networks. In Progress follows Finder's tracker-aware progress data, while the discovery widgets use Finder's existing TMDb or Trakt list actions.

Providers and Networks use Finder's category navigation rather than maintaining a separate provider system in the skin. This keeps the Finder Skin widgets tied to the same menus and data paths used by Finder itself.

Skin Settings -> Widgets offers Use WideInfoWall Layout for Home Media Widgets. This affects home media widgets only; Search retains Poster View 54. Movie/TV media lists use List View 50; standard navigation menus use Wide List View 55. Category pills retain their established footprint, with translucent interiors and notification-style borders.
