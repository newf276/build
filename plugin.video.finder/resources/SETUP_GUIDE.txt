Finder and Finder Skin Setup Guide — 1.0.08.8

1. Install plugin.video.finder from Newf276's repository or the supplied ZIP. If you choose Finder + Finder Skin during first-run setup, Finder checks for skin.finder and can install it for you when needed. You do not need to activate Finder Skin manually before beginning setup.
2. On first use, choose Finder + Finder Skin for the integrated interface or Finder Standalone to use the add-on without Finder Skin. In integrated mode Finder activates Finder Skin and continues directly to its Pre-Config selector.
3. In Finder Skin Pre-Config, choose the configuration for your Primary Tracker: Finder, Trakt or PunchPlay. Complete authorization when required. PunchPlay first-run setup synchronizes watched history and supported lists; Repair PunchPlay Watched Database remains available later if repair is ever needed.
4. Allow the first-run sequence to finish. Finder coordinates Pre-Config, tracker authorization and the initial synchronization/rebuild before completing the interface handoff. Do not manually back out while authorization or synchronization is still in progress.
5. When the selected tracker is ready, Finder saves Finder Skin as Kodi's selected skin, completes the final skin handoff and automatically opens a fresh Finder Home screen. When that Home screen appears, first-run setup is complete and Finder is ready to use. No manual skin selection, backing out to Home, Kodi exit or Kodi restart is required. Finder Skin remains selected on later Kodi restarts.
6. In Finder -> My Lists, select Authorize TMDb, Authorize Trakt or Authorize PunchPlay for a signed-out account. Yes launches its existing sign-in flow. No suppresses automatic recovery reminders; a manual selection can ask again. Leave and reopen My Lists after signing in.
7. Customize menus and widgets in Skin Settings after first-run setup if desired. The home paths remain Finder-native. Optional home WideInfoWall layout is under Skin Settings -> Widgets. Search stays Poster View 54; movie/TV lists use List View 50 and normal navigation uses Wide List View 55.
8. Open First Unwatched Episode is enabled by default under Finder Settings -> Content -> General. Supported shows open to and focus the first aired unwatched episode while watched episodes remain available. Disable it for normal browsing.
9. Use ExtendedInfo from Finder's context menu or Kodi Info for Finder items in Finder Skin. Play/Browse, Options, Sync and Play Trailer use Finder capabilities. Actor biographies, credits, related titles, seasons, videos and artwork are available where metadata exists.
10. Native Finder trailers do not require the YouTube add-on. Trailer playback follows Finder's current trailer settings; individual videos can still be restricted or unavailable.
11. Enable top-right weather in Skin Settings and configure Kodi's weather service/location using the provided shortcut.
12. MDbList currently provides ratings only, not watched tracking. Configure the existing MDbList ratings key through the available skin/Finder authorization controls. Shared-key/personal-key enhancements remain planned, not included in this release.
13. Use Finder Tools for cache maintenance, account settings, Tips for Use and log upload. Clear Progress is available on supported In Progress items. Do not clear databases merely to install this release. If troubleshooting, confirm both Finder and Finder Skin versions and provide a debug log.
14. Finder Skin uses four status indicators on supported Finder media views: outlined circle with center dot = untouched; half-filled circle = a TV show is partially watched; eye = that exact movie/episode has a stored resume point; circle with check = watched/completed. In Progress TV shows are ordered using recent watched activity and resumable episode activity, so a show you just resume can move to the front.
15. Tools also provides two reset levels: yellow Reset Finder Settings to Defaults restores preferences while preserving accounts, API credentials, setup state, watched data, personal lists and caches; red Factory Reset Finder is destructive and returns Finder to the first-run Welcome flow after the next full Kodi restart.
