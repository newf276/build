Finder ExtendedInfo

Layout and window navigation adapted from Angelitto's TMDbMovies 1.1.308
ExtendedInfo component (extended_info_mod.py and ext_* layouts/assets).
Finder supplies playback, options, tracker sync, watched status, metadata cache,
and trailer playback. No TMDbMovies provider services or API keys are included.
